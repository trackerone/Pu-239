# Contributing

Thank you for contributing 💪

## Flow
1. Create a branch from `develop`
2. Keep PRs small and focused
3. Provide a short description in the PR and tick the checklist

## Code style & static analysis
- Pint: `pint --test` (runs in CI as *soft guard*)
- PHPStan: `phpstan analyse` (runs in CI as *soft guard*)

## Releases
- Merge into `main` happens via PR after review
